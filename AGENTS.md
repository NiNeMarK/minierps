# Agent Instructions & Guidelines

## Next.js Project Rules & Conventions

> **IMPORTANT:** This project uses a custom/updated version of Next.js with breaking changes. Do **NOT** rely solely on pre-existing Next.js training data or standard patterns.

### Mandatory Directives

1. **Check Local Documentation First**
   - Before writing or refactoring any code, APIs, or file structures, read the relevant guides located in:
     `docs/`
   - Verify that proposed imports, routing conventions, and configurations match the local documentation.

2. **Strict Adherence to Breaking Changes & Deprecations**
   - Strictly honor all deprecation notices and breaking change warnings found in the local documentation or build outputs.
   - Do **NOT** use deprecated APIs, configuration flags, or legacy paradigms.

3. **Code Generation Requirements**
   - Always verify export signatures, dynamic route conventions, and data-fetching methods against the docs in `docs/`.
   - Prioritize type safety and compatibility with the current module setups.
